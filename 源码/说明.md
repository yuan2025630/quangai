原生窗口源码位于 `desktop`，最终网页资源位于 `../发布/圈改/web`。这是当前正式版本的源码和资源，不保留历史副本。

使用 .NET 10 SDK 构建：

```powershell
dotnet publish .\desktop\Quangai.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o "$env:TEMP\quangai-publish"
```

构建结果在指定临时目录中。验证后将其中的 `圈改.exe` 更新到 `../发布/圈改`；网页资源直接维护正式目录中的对应文件。保留发布目录内的图标、运行资源和许可文件。

仓库根目录的 `scripts/check.ps1` 可运行全部独立检查，`scripts/package.ps1` 会生成含完整资源、许可文件和 SHA-256 的 Windows ZIP。公开构建排除 `web/wallpapers/` 下的个人素材。内置原生回归使用嵌入的原创 WebM 测试片，不依赖第三方壁纸。
