# 圈改 · 项目前端与演示文稿修改的人工干预与验收

圈改是一款面向各种项目前端和各类演示文稿修改的人工干预与验收工具。导入前端界面截图、图片或 PPT/PPTX，由人圈出需要修改和必须保留的区域，写清要求，交给 AI Agent 或协作者修改对应的前端源码或演示文稿，再导入实际运行截图或修改后的完整 PPT 逐项核对。

人工决定修改范围、参考关系和验收结果；圈改把这些判断整理成可交接、可追踪的修改意见。核心功能在本机运行，无需账户或模型 API。

## 主要使用场景

- **各种项目前端的修改：** 对网站、后台、应用界面等截图圈选，明确布局、字号、配色、间距等调整要求，指导协作者落实到前端源码。
- **各类演示文稿的修改：** 对汇报、课程、路演、学术演示等 PPT 逐页提出内容、布局和样式要求，准确定位需要修改的页面。
- **明确修改与保留约束：** 区分要调整与不能改变的内容，结合局部参考和整体要求，控制本轮修改范围。
- **逐项核对与验收：** 前端通过实际运行截图核对，演示文稿通过完整修改稿逐页核对，使用并排、滑动和差异对照，由人逐条确认结果。

也可用于普通图片的局部修改反馈，使用同一套圈选、交接和核对流程。

## 下载与运行

在 [Releases](https://github.com/yuan2025630/quangai/releases/latest) 下载 `quangai-0.1.11-win-x64.zip`，完整解压后运行 `圈改/圈改.exe`。保留程序旁的 `web`、图标与许可文件。

PPT 导入需要 Microsoft PowerPoint 桌面版；图片功能无需 Office。程序以禁用宏、只读方式生成 PPT 预览，不覆盖原件。Windows x64 包已含 .NET 运行时；运行需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

`圈改.exe` 通过 Releases 提供，克隆仓库后需自行构建原生程序。

## 四步开始使用

1. **导入文件：** 选择或拖入图片、PPT/PPTX；截图可 Ctrl+V 粘贴。
2. **圈出要求：** 单击“修改”或“保留”沿用上次圈选方式，双击才选择形状；圈选后在右侧写具体要求。PPT 各页独立标注。
3. **导出交接：** 本机 Agent 用“导出协作目录”并复制提示词；其他协作者用“导出 ZIP 修改包”。通常只导出“本轮待修改”。
4. **核对并完成：** 图片协作目录可自动接收 Agent 提交的 PNG，其他图片和完整修改 PPT 手动导入。逐条确认后点击“完成并保存”。

所有项目自动保存到统一目录，不必先选保存位置。软件内“使用方法”可随时查看四步帮助，详细操作见 [使用说明](发布/圈改/使用说明.md)。

## 主要功能

- 矩形、椭圆、自由画圈选，修改与保留工具各自记住上次形状，支持局部参考图。
- 统一项目库：新建、旧草稿、导入旧项目统一保管，自动保存；按名称搜索、图片/PPT筛选及回收站删除。
- 直接导入 `.ppt` / `.pptx`，缩略图或输入页码跳转、独立标注和核对；仅看待修改页时，前后导航在待修改页间移动。
- PPT 预览可切换单行、全部网格和完整收起顶部区域，支持调节缩略图大小并记住偏好；缩略图按需加载，后台自动降低内存占用。协作提示词明确源文件、目标页和交付位置。
- PPT 导出按准确页码和 SlideID 定位本轮任务，附完整可编辑源文件。完成后手动导入完整修改 PPT 核对。
- 图片导出 ZIP 或本机 Agent 协作目录；目录回传校验轮次与 SHA-256 后自动载入。
- 并排、滑动、按住、差异四种核对方式，支持缩放和保留区域变化提示。
- Ctrl+S 立即保存、关闭标签或退出前完成保存，写入失败保留窗口并提示原因。
- 本机 Wallpaper Engine 壁纸库、搜索收藏与轮播，支持完整视频、兼容的场景/网页和玻璃外观调节。

项目默认保存在“文档\圈改项目”。“项目库”可更换并迁移全部项目及回收站，原位置保留备份。PPT 项目备份时须保留完整项目文件夹中的 `源文件`。详见 [项目与 PPT 验证](项目与PPT说明.md)。

## 仓库结构

```text
源码/desktop/       C# WinForms / WebView2 原生窗口源码
源码/tests/         项目库与 PPT 行为检查
scripts/           一键验证与公开版 Windows 打包
.github/workflows/ Windows 自动验证和构建产物
发布/圈改/web/      HTML、CSS、JavaScript 与运行资源
发布/圈改/licenses/ 第三方许可文件
发布/圈改/          使用说明、开源说明、图标与快捷方式脚本
```

网页资源直接在 `发布/圈改/web` 中维护。仓库不包含此前的 Vite 工程或 `package-lock.json`。

## 构建 Windows 发布包

安装 .NET 10 SDK 和 Node.js 22 或更新版本，在仓库根目录执行：

```powershell
.\scripts\check.ps1
.\scripts\package.ps1
```

验证涵盖 JavaScript 语法、PPT/自动保存/协作工作流、缩略图生命周期、项目库与壁纸库边界，以及 Windows 编译。打包结果位于 `output/releases`，含 ZIP 和 `SHA256SUMS.txt`。每次推送及 PR 会运行同一组 Windows 检查并生成可下载的构建产物。

CI 不包含实体桌面交互、PowerPoint 自动化或真实协作者回传，这些需要安装相应软件后单独验证。仓库没有上传个人项目、浏览器配置、密钥或本机 Wallpaper Engine 素材。

## 版本与许可说明

当前版本为 `0.1.11`。本版降低后台驻留内存，支持完整收起 PPT 顶部区域，按需释放缩略图，并减少自动保存重复写入和 PPT 图片数据的反复序列化。公开 Windows 包仅含原创默认背景；本机 Wallpaper Engine 库和自定义视频仍可使用。发布包的校验值见对应 Release 的 `SHA256SUMS.txt`。

PPT 对象修改由协作者完成；圈改负责定位、交接和核对，不直接调用外部 AI。壁纸实现与验收见 [壁纸升级说明](壁纸升级说明.md)，此前的功能验收见 [验收记录](验收记录.md)。

第三方组件的许可与来源见 [开源说明](发布/圈改/开源说明.md) 及 `发布/圈改/licenses/`。第三方组件的许可证仅适用于各自组件；本项目原创代码暂未另行指定开放源码许可证。
