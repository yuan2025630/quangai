# 圈改 0.1.11 · 使用说明

圈改把修改要求画在图片或 PPT 页面上，再逐条核对修改稿。先完成下面四步；需要时再看后面的详细操作。核心功能在本机运行，无需账户或模型 API。

## 四步上手

双击 `圈改.exe` 打开软件，保留旁边的 `web` 文件夹。点击软件里的“使用方法”可随时查看这四步。

1. **导入文件。** 点击“导入文件”选择图片、PPT 或 PPTX，也可把文件拖到画布。空画布也提供导入按钮和四步提示；截图可用 Ctrl+V 粘贴。已有项目从“项目管理”打开。
2. **圈出要求。** 单击“修改”或“保留”，拖动圈选区域，在右侧填写意见；双击工具按钮才选择矩形、椭圆或自由画。PPT 先选中要修改的页，每页分别保存意见。
3. **导出交接。** 点击右上角“导出”，通常选择“本轮待修改”。本机 Agent 用“导出协作目录”，再“复制 Agent 提示词”；发给其他人或网页 AI 用“导出 ZIP 修改包”。
4. **导入并核对。** 图片协作目录支持 Agent 提交后自动载入；其他图片结果从“导入修改稿”导入。PPT 必须导入修改后的完整 PPT。切到“核对结果”，逐条选择“已满意”“还需修改”或“暂缓”；全部完成后点击“完成并保存”。

项目会自动保存在统一文件夹，开始操作前无需选保存位置。Ctrl+S 可立即保存；关闭标签或退出前会完成保存，写入失败时保留窗口并提示原因。

## 找到、管理和备份项目

点击“打开项目”或“项目管理”查看所有项目。输入项目名称搜索，也可筛选图片或 PPT 项目。列表中的“打开”继续编辑，“文件夹”查看该项目的文件。

默认使用“文档\圈改项目”，可在“项目库”中更换位置。新建项目、恢复的旧草稿、导入的旧项目都归入这里，每个项目有独立文件夹：

| 内容 | 用途 |
| --- | --- |
| `项目.quangai.json` | 图片、各页标注、参考关系和核对状态 |
| `源文件/` | 导入的完整 PPT 副本 |
| `导出/` | 本机协作轮次与 PPT 修改包 |

- **新建和改名：** 点击“新建”或标签右侧“＋”；双击项目标签或按 F2 改名，Enter 确认、Esc 取消。“完成并保存”记录完成时间，标签仍保留供查看。
- **导入旧项目：** 在管理面板选择“导入旧项目文件”。程序创建受管副本并保留外部原件。PPT 项目须一并保留旁边的 `源文件`，或导出包的 `source` 目录。
- **删除和恢复：** “删除”把整个项目移入统一目录的 `.项目回收站`。点击“打开回收站”，将要恢复的项目文件夹移回统一目录，再“刷新”列表。外部原始图片和 PPT 不会随项目删除。
- **更换位置：** “更换并迁移全部项目”复制全部项目及回收站到新位置，原位置保留迁移备份。新旧目录不能互相包含。
- **备份和分享：** 备份整个项目文件夹；PPT 项目需要连同 `源文件` 一起保留。给协作者交接本轮要求，优先使用导出的 ZIP 修改包。

顶部标签可同时打开多份项目，各自保留图片、意见、撤销记录和查看位置。重新打开软件会恢复标签；标签的草稿用于恢复工作区，项目内容同时写入统一项目库。

## 在任意 PPT 页上修改

导入 `.ppt` / `.pptx` 需要 Microsoft PowerPoint 桌面版。程序以禁用宏、只读方式生成页面预览，保留完整可编辑副本；标注和核对不覆盖导入原件。

画布上方的缩略图显示页码和待修改标记。点击缩略图或输入页码直接跳转，用前后页按钮继续浏览。每页的标注和核对状态独立保存，切页不会丢失意见。

预览方式可自由选择：“单行预览”横向浏览，“预览全部”按网格展开当前筛选范围的页面。“收起预览”会一起收起 PPT 名称、页码、跳转、筛选、预览控制栏和缩略图，只保留“展开预览”按钮。展开时恢复先前的预览方式、大小和筛选；“预览大小”可调节缩略图大小，偏好会自动记住。

PPT 缩略图按可见范围生成小图，滚出视野、收起或最小化时释放；画布和导出继续使用原始预览。切换到其他窗口五秒后、或最小化时，圈改自动降低 WebView2 内存占用，返回窗口时恢复正常模式；后台仍可自动保存和接收协作回传。

勾选“仅看待修改页”，可集中处理待核对或还需修改的页面；前后页按钮只在这些页面之间移动。缩略图获得焦点后也可用方向键、Home / End 导航，网格中上下键按行移动，当前页自动滚入预览可见范围。

PPT 导出固定使用“修改项目内容”，保存到当前项目的 `导出` 目录。修改清单给出准确页码、SlideID 和意见，只为待修改页生成预览、标注和局部图，同时附完整可编辑 PPT。只有保留、参考或已满意意见的页面不会单独成为新任务；其他页的内容、样式和顺序应保持。

协作者完成后，从“导入修改稿”选择**修改后的完整 PPT**。程序检查页数、顺序和 SlideID，匹配成功后可逐页核对；不匹配时保留当前项目并提示原因。请让协作者在原文件上修改，避免另建演示文稿或重新插入全部幻灯片。

PPT 修改稿采用手动导入。圈改提供标注、定位、交接和核对，不自动编辑 PPT 对象。“用修改稿替换原图”会把完整修改后 PPT 和所有页预览一并作为新原稿，保留意见，可用 Ctrl+Z 撤销。

## 把要求写清楚

“修改”和“保留”分别记住上次使用的圈选方式，重启后仍保留。单击直接使用，双击打开矩形、椭圆、自由画菜单。聚焦工具后按 Alt+↓ 也可打开菜单，方向键选择、Enter 确认、Esc 关闭。

圈选后，在右侧写出“改哪里、改成什么、哪些保持”。例如：“标题缩小一档，仍居中；其余字体和配色保持。”用“保留”圈出不能改变的区域；展开“整体要求”补充全局约束。

需要局部参考时，先选中一条修改意见，再用“参考”导入参考图并圈出借鉴部分。右侧可调整关联意见，或设为整体参考，并写明用途。

| 操作 | 方法 |
| --- | --- |
| 移动或改大小 | “选择”拖动标注；双击已有框进入拉伸，拖动边角手柄，Esc 结束 |
| 精确定位 | 展开右侧“位置与尺寸”，输入像素位置和宽高 |
| 删除与恢复 | 选中意见后点击删除或按 Delete；Ctrl+Z 撤销；框内右键也可删除 |
| 看细节 | Ctrl+鼠标滚轮以指针位置缩放；画布获得焦点后按 + / − 缩放、0 自适应、1 显示原始尺寸 |
| 临时平移 | 画布获得焦点后按住空格拖动，或直接按住鼠标中键拖动；松开后继续使用原来的工具 |
| 取消当前拖动 | 按 Esc 放弃本次圈选、移动或拉伸；切换窗口时也会取消未完成的拖动 |
| 连续微调 | 方向键移动 1 图片像素，Shift+方向键调整尺寸；按住同一方向键的一次连续移动可一次撤销 |
| 调整意见栏 | 拖动画布与意见栏之间的细线；双击恢复默认；标题旁“…”也可调整 |

图上的框、编号和箭头属于标注，原图文件保持不变。删除意见后，导出编号保持稳定。画布“隐藏”可临时隐藏图片和标注、露出壁纸，再点击“显示”恢复，不影响导出。

## 选择合适的导出方式

点击“导出”先确认修改单名称、修改方式、意见范围和文字预览。

图片项目可以选择“仅修改图片”，要求交付完整 PNG；需要改真实 UI 源码等工程时，选择“修改项目内容”，并让协作者能访问对应源工程。圈改的项目快照保存标注意见，不包含该 UI 工程源码。PPT 已自动固定为“修改项目内容”，附带完整源文件。

“本轮待修改”只执行待核对、还需修改的意见，并带上保留约束与适用参考。“全部意见”补充已满意和暂缓意见作为上下文；已满意项保持，暂缓项不执行。缺少具体要求时会提醒补充。只有保留或参考、没有修改任务时，无需生成新稿。

### 本机 Agent：图片可自动回传

1. 点击“导出协作目录”，当前项目的 `导出` 目录会为本轮建立独立文件夹，无需解压。
2. 点击“复制 Agent 提示词”，发给能读写本机文件的 Agent。“打开目录”可检查素材。复制提示词本身不会自动发送消息或调用模型。
3. Agent 按要求修改实际内容，生成完整 PNG 后，使用目录中的 `submit_result.py` 或 `instructions.md` 提交。脚本需要 Python 3，圈改自身不需要 Python。
4. 圈改校验轮次和 SHA-256 后自动载入图片修改稿，切到核对。最终是否满意仍由你判断。

UI 工程模式应从修改后的实际内容截图或渲染核对 PNG。无法运行或生成真实预览时，协作者应交付修改文件并说明未验证部分。

每次导出新建一轮，旧目录和原图快照保留。侧栏显示连接和回传状态；“断开”停止当前连接，文件保留。重启会恢复连接，相同回传结果不会重置已确认状态。删除或移动当前协作目录后，需要重新导出。

PPT 协作目录交接完整可编辑 PPT 和指定页要求；复制的提示词会列出本轮真实目录、`source/original.pptx`（旧格式为 `.ppt`）、目标页与 SlideID，以及 `result/revised.pptx` 的交付位置。`project.quangai.json` 是标注快照，实际修改入口为可编辑 PPT。完成后手动导入完整修改 PPT。ZIP 内也附有 `agent-prompt.txt`，以解压后的目录为基准。导出后修改意见需重新导出，再复制提示词。普通网页聊天或无法访问本机目录的云端 Agent，也应使用下载后手动导入的方式。

### ZIP：交给其他人或网页 AI

“导出 ZIP 修改包”生成可分享的素材和清单。将 ZIP 或其中的原图、标注图、参考图与 `instructions.md` 一起交给协作者；文件不会自动发送。收到完整图片或 PPT 后，在圈改“导入修改稿”。普通 ZIP 不绑定本机自动回传，即使项目曾连接协作目录也需手动导入。

图片导出的主要文件如下；PPT 则将待修改页素材分放在 `pages/page-XXX/`，完整可编辑文件放在 `source/`。

| 文件 | 用途 |
| --- | --- |
| `original.png`、`annotated.png` | 原貌和带编号标注 |
| `instructions.md`、`annotations.json` | 文字清单和机器可读的位置、意见 |
| `crops/` | 每条意见的局部图 |
| `reference.png`、`reference-annotated.png` | 有参考图时附带 |
| `revised.png` | 已有修改稿时附带 |
| `project.quangai.json` | 可在圈改继续编辑的标注快照 |

图片协作目录另有 `agent-prompt.txt`、`submit_result.py` 和 `agent-session.json`。新结果提交到 `result/revised.png`，完成标记为 `result/ready.json`；目录根部的 `revised.png` 是导出时已有的修改稿。

## 核对结果，再开始下一轮

在“核对结果”中点击右侧意见，查看对应局部；PPT 先选中对应页面。

| 核对方式 | 操作 |
| --- | --- |
| 并排 | 左侧原图、右侧修改稿，适合整体观察或尺寸不同的文件 |
| 滑动 | 拖动画面中的竖线；聚焦竖线后可用方向键、Home / End |
| 按住 | 默认显示原图，按住图片显示修改稿；聚焦图片后按住空格或 Enter 也可对照 |
| 差异 | 淡化原图，用红色高亮检测到的变化 |

逐条设置“已满意”“还需修改”或“暂缓”。需要下一轮时，导出“本轮待修改”；全部完成时“完成并保存”。保留区域变化会提示，是否违背要求需人工判断，像素差异不能证明要求完成。

想在修改稿上继续标注，点击“用修改稿替换原图”。意见、核对状态和参考关系保留，尺寸变化时按相对位置保留标注；旧轮次连接结束，下一轮重新导出。Ctrl+Z 可撤销替换。PPT 替换完整演示文稿及全部页预览。

不同尺寸仅支持并排；大图会缩小采样，低于阈值的细小变化可能不进入统计。截图的缩放、裁切或位置变化也会影响对照。

## 壁纸、布局和文件选择

“壁纸”打开“壁纸与氛围”。壁纸库可发现本机 Wallpaper Engine 工程，支持搜索、类型筛选、收藏、隐藏和轮播；找不到目录时使用“添加壁纸库目录”。图片、视频及兼容的场景、网页壁纸可使用，应用程序壁纸不支持；效果与脚本的兼容程度取决于原工程。切换失败会保留当前壁纸。

“外观”可调整背景亮度、暗化、模糊和玻璃面板；“播放”可暂停、调音量和速度、设置离开窗口时暂停。壁纸只装饰工作台，不进入原图、标注图或修改包。本机库视频播放完整源文件；手动添加的视频限 100 MB。偏好独立于项目保存，重启后恢复。

标题栏空白处可拖动窗口，双击最大化或还原。最大化保留 Windows 任务栏，窄屏时工具换行、意见栏移到画布下方。移动软件后可运行 `创建桌面快捷方式.ps1` 重新建立快捷方式。

导入图片、参考图、修改稿等文件选择会记住最近确认的目录；仅浏览后取消不会更新。项目保存和本机协作导出由统一项目库管理，无需每次另选位置。

## 常用快捷键

| 按键 | 操作 |
| --- | --- |
| V / B / P / H / R | 选择 / 修改 / 保留 / 小手 / 参考 |
| Ctrl+S | 立即保存到统一项目库 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| Delete | 删除所选标注 |
| Ctrl+V | 粘贴截图；先将焦点移出文字输入框 |
| Ctrl+鼠标滚轮（画布内） | 放大 / 缩小 |
| F2（项目标签获得焦点时） | 修改项目名称 |
| 方向键 / Shift+方向键 | 移动所选标注 1 像素 / 调整矩形宽高 5 像素 |
| Enter（画布获得焦点时） | 用当前工具在中心添加标注 |

输入框中保留正常文字编辑快捷键。工具栏“添加”也能创建矩形，再输入位置和尺寸。

## 常见问题与范围

- **PPT 不能导入：** 确认安装的是 Microsoft PowerPoint 桌面版。单个文件限 100 MB、1–400 页，预览合计最多 100 MB。
- **PPT 修改稿不能配对：** 需交回完整文件，并保留原页数、顺序和 SlideID；不要只交修改页、截图或另建的 PPT。
- **图片没有自动载入：** 确认使用“导出协作目录”、当前连接仍有效，且 Agent 按本轮协议提交了 PNG 和完成标记。ZIP 和网页聊天结果请手动导入。
- **保存报错：** 按提示检查统一目录是否可访问、是否有写入权限；窗口会保留，处理后按 Ctrl+S 再保存。
- **运行提示缺少组件：** Windows x64 发布包已含 .NET 运行时；WebView2 Runtime 可从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。

图片项目支持一张原图、参考图及修改稿；PPT 每页分别保存对应图片与标注。图片限 40 MB、边长 8192 像素、2400 万总像素，每页或图片项目最多 300 条标注。导入图片转为 PNG，动图按静态图片处理。

圈改通过画面坐标交接要求，不自动识别网页元素、PPT 对象或源码，也不直接调用外部 AI。
